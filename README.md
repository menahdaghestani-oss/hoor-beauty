
# Hoor Beauty Center 🌸

A modern, elegant and responsive website for **Hoor Beauty Center**, designed to introduce beauty and skincare services and make it easier for visitors to explore the center and request appointments.

## 🌐 Live Website

https://menahdaghestani-oss.github.io/hoor-beauty/

## 📌 About the Project

Hoor Beauty Center is a bilingual website project built using HTML5 and CSS3.

The website provides information about the center, its services, contact details, and appointment registration.

The design combines elegant colors, clear navigation, responsive layouts, and interactive elements to create a pleasant browsing experience.

## 📄 Website Pages

The project includes the following pages:

| Page | Description |
|---|---|
| `index.html` | Arabic homepage |
| `about.html` | About the center |
| `videos.html` | Video gallery |
| `register.html` | Appointment registration |
| `contact.html` | Contact information |
| `index-en.html` | English homepage |
| `about-en.html` | About the center in English |
| `videos-en.html` | English video gallery |
| `register-en.html` | English appointment registration |
| `contact-en.html` | English contact information |

## ✨ Main Features

- Bilingual Arabic and English content.
- Responsive design for mobile phones, tablets, and computers.
- Sticky navigation menu.
- Internal and inline CSS styling.
- Hover effects and smooth scrolling.
- Appointment registration form.
- WhatsApp contact integration.
- HTML5 video players.
- Service descriptions and organized content.
- Contact details and branch information.

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages
