# Hoor Beauty Center Website

A responsive bilingual website for Hoor Beauty Center, created using HTML, CSS, and JavaScript.

## Website Languages
- Arabic
- English

## Website Pages
- Home
- About Us
- Videos
- Appointment Request
- Contact Us

## Features
- Responsive design for mobile and desktop.
- Bilingual navigation.
- HTML tables and lists.
- Images and HTML5 video players.
- Appointment request form connected to WhatsApp.
- Contact links for phone, email, and WhatsApp.
- CSS hover effects and responsive layouts.
- Semantic HTML structure.

## Technologies
- HTML5
- CSS3
- JavaScript
- Google Fonts
